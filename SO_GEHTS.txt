===============================================================================
 Arena Studio Connector - Schnellstart
 Verbindet Roblox Studio mit Arena AI
===============================================================================

1. ENTPACKEN (wichtig!)
   Rechtsklick auf die ZIP-Datei -> "Alle extrahieren ..."
   Bitte NICHT die .bat direkt aus dem ZIP-Fenster starten - dann fehlen
   Dateien wie plugin\ArenaBridgePlugin.lua.

2. STARTEN
   Doppelklick auf:  ArenaStudioConnector.bat
   - Ist Python 3 noch nicht installiert, fragt die Datei, ob sie es
     automatisch installieren darf (winget) - oder oeffnet die Download-Seite.
   - Die App oeffnet sich als Fenster (ohne Konsolenfenster).

3. SO LAEUFT ES AB
   a) Doppelklick auf ArenaStudioConnector.bat
      -> im Fenster stehen Tunnel-URL, Token und die lokale URL
      -> der Prompt fuer Arena AI liegt in der Zwischenablage
      -> Fenster OFFEN LASSEN (das ist die Bridge)
   b) Roblox Studio -> Plugins-Tab -> ArenaBridge
      -> Bridge-URL = http://127.0.0.1:8765   (lokale URL aus dem Fenster)
      -> Token      = ...                      (Token aus dem Fenster)
      -> "Verbinden" klicken (wird gespeichert, naechstes Mal automatisch)
      (Das Plugin wird automatisch nach
       %LOCALAPPDATA%\Roblox\Plugins\ArenaBridgePlugin.lua installiert)
   c) Bei Arena AI einfuegen (Strg+V) und darunter schreiben, was gemacht
      werden soll - oder die Zeile "<HIER EINTRAGEN ...>" ersetzen
   d) Beenden: im .bat-Fenster Strg+C

4. OPTIONAL: Creator-Dashboard-Aktionen (GamePaesse, Dev-Produkte, Badges ...)
   Dafuer braucht Arena einen Roblox Open-Cloud API-Key. Der Key bleibt IMMER
   auf deinem PC - er wird nie in den Prompt kopiert und nie verschickt.
   - .env.example kopieren und die Kopie exakt ".env" nennen
   - Anleitung + benoetigte Rechte stehen ausfuehrlich in der .env.example

PROBLEME?
   Fenster blitzt nur kurz auf?
     - ZIP-Datei VOR dem Entpacken zulassen: Rechtsklick auf die ZIP ->
       Eigenschaften -> "Zulassen" anhaken -> OK -> dann entpacken
     - nicht direkt aus der ZIP-Vorschau starten
     - Win+R -> cmd -> cd /d "<Ordner>" -> ArenaStudioConnector.bat /console
   Diagnose.bat                      -> schreibt diagnose_log.txt mit allen
                                        Infos (Python, tkinter, Dateien, --check)
   ArenaStudioConnector.bat /gui     -> optionale App mit Fenster (Places-Liste)
   ArenaStudioConnector.bat /places X-> Places von Roblox-User X anzeigen
   ArenaStudioConnector.bat /check   -> Systemcheck: Python, tkinter, Plugin,
                                        Port, cloudflared, Plugin-Ordner
   ArenaStudioConnector.bat /plugin  -> Studio-Plugin sofort (neu) installieren
   ArenaStudioConnector.bat /newtoken-> neuen Bridge-Token erzeugen + Plugin
                                        neu schreiben (alter Token ungueltig)
   ArenaStudioConnector.bat /unblock -> Windows-Sperre "Datei aus dem Internet"
                                        entfernen, falls Windows blockt
   last_error.log                    -> entsteht automatisch, wenn die App beim
                                        Start abstuerzt (mit Fehlerdetails)

DATEIEN IN DIESEM ORDNER
   ArenaStudioConnector.bat          Der Starter (hier doppelklicken!)
   ArenaStudioConnector-Konsole.bat  Gleiches, aber mit Meldungen
   Diagnose.bat                      Fehlersuche: schreibt diagnose_log.txt
   arena_studio_connector.py         Die App selbst (GUI + Bridge + Tunnel)
   VERSION                           Version der App (fuer /version)
   plugin\ArenaBridgePlugin.lua      Roblox-Studio-Plugin (wird beim Start
                                     automatisch nach %LOCALAPPDATA%\Roblox\Plugins
                                     installiert)
   .env.example                      Tutorial fuer den Roblox API-Key
   config.example.json               Vorlage fuer config.json (Username, Port)
   prompt_beispiel.txt               So sieht der kopierte Prompt aus
   README.md                         Alles ausfuehrlich erklaert

SICHERHEIT
   Bridge-Token und Tunnel-URL gelten nur, solange die App laeuft.
   Prompt/Token nur an Arena AI geben - nicht oeffentlich posten.
   Der Roblox API-Key verlaesst deinen PC nie (liegt in .env / config.json).
